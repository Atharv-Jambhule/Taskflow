# 🚀 TaskFlow - MERN Task Management System

TaskFlow is a modern MERN Stack task management application inspired by productivity platforms like Jira and GoodDay.

## Features

- User Authentication (JWT)
- Login & Registration
- Task Creation
- Task Deletion
- Task Search
- Task Priority Levels
- Due Date Support
- Task Status Updates
- Kanban Workflow
- Analytics Dashboard
- Profile Popup
- Responsive UI
- MongoDB Atlas Integration

---
